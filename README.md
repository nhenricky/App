# Todo List

Uma lista de tarefas simples feita com **HTML, CSS e JavaScript**.

## Funcionalidades

* Adicionar tarefas
* Marcar tarefas como concluídas
* Remover tarefas
* Salvar tarefas no navegador com `localStorage`

## Tecnologias

* HTML5
* CSS3
* JavaScript
